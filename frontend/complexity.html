📐 指标是怎么算出来的

全部指标基于编译器既有的词法 token、AST 与字节码控制流，不做文本猜测。
  • 圈复杂度（Cyclomatic Complexity）：McCabe 定义。在函数的控制流图上 V(G) = E − N + 2（函数单入口单出口，P=1）。本页直接把代码生成器产出的字节码切成基本块、连出真实的条件跳转/回边后计算；每个 if/elif 条件、while/for 循环、以及 &&/|| 的短路跳转都增加一条独立的边。else 不增加复杂度。
  • 最大嵌套深度：沿 AST 统计 if / while / for 代码块相互嵌套的最大层数（函数体本身为第 0 层），多层嵌套会被如实计入。
  • 行数：物理行 = 函数 { 到配对 } 的跨度；有效代码行（SLOC）= 词法分析后含 token 的行；纯注释行（//、/* */）与空行单独统计。
  • 语句数 / 参数数 / 调用数：遍历 AST 统计；print 等内置调用会在展开明细中标注。
  • 递归：在「用户函数 → 用户函数」调用图上用 Tarjan 强连通分量识别——自环是直接递归，多点成环是互相（间接）递归，并给出调用环。
