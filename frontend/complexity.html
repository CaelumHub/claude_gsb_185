📐 指标口径与计算方法

所有指标均由现有编译产物计算，不引入新的解析器或第三方依赖：
圈复杂度 v(G) 从每个函数（含顶层 <main>）的字节码构建控制流图（CFG）： JUMP_IF_FALSE / JUMP_IF_TRUE 各对应一个分支谓词 （if/elif、while/for 条件，以及 && / || 的短路跳转）， 故 v(G) = 1 + 谓词数；同时补一个虚拟出口节点用经典公式 E − N + 2 交叉验证，两者必须相等（逐函数有「对账」标记）。
嵌套深度 遍历语义分析后的 AST：进入 if/elif/else、while、for 的函数体时深度 +1， 取整个函数内的最大值；条件表达式内部的 &&/|| 属于谓词而非词法嵌套，计入圈复杂度但不计嵌套深度。
行数 物理行＝函数 func 行到函数末行；SLOC 再扣除空行与 //、/* */ 注释行；可执行行＝该区间内带字节码指令的源码行数。
调用与递归 模拟栈式字节码，配对 LOAD_FUNC … CALL 得到用户函数调用边 （内置函数不计）；对调用图求 Tarjan 强连通分量：自环＝直接递归， 多节点环＝相互递归。
break / continue 编译为无条件跳转（JUMP），不产生新谓词，因此不增加圈复杂度，但单独计数展示。
